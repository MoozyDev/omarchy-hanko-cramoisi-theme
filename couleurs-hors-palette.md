# Cramoisi — couleurs utilisées hors colors.toml

| Usage | Hex |
|---|---|
| Fond des images (fonds d'écran, verrouillage, déverrouillage disque) | `#c8102e` |
| Accent (identique à colors.toml) — aussi clavier Wooting | `#ff3355` |
| Accent foncé (petits textes d'accent sur fond crème, ex. en-tête de notification) | `#a50d26` |
| Crème (texte sur les images) | `#f1e7d6` |
| Noir (disque, champs) | `#121010` |

## Déverrouillage du disque (Plymouth)
- Logo : `unlock.png` (logo Moozy)
- Couleur de fond : `#c8102e`
- Couleur du texte : `#f1e7d6`

## Menu de démarrage (Limine)
Voir `boot/limine.conf` : bloc prêt à coller (clés Limine 12.9.4, hex sans #).
À régler une seule fois, sur le thème principal.
